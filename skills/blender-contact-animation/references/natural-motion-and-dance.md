# 자연스러운 연기·다양한 동작·춤 만들기

모션의 종류/표현 폭을 넓히거나 음악·여러 배우·클립 전이를 다룰 때 사용한다.
리그 자체가 잘못됐으면 전신/손 기준으로 먼저 고친다. 이 문서는 제작 방법이며,
설치된 모든 모델이 춤·연기·물체 조작을 이미 잘한다는 보증이 아니다.

성격·감정·key pose·gaze/face·moving hold·secondary hierarchy의 공통 설계는
[`character-performance-animation`](../../character-performance-animation/SKILL.md)이 소유한다.
이 문서는 모션 원천 선택, Blender 구현, 음악 위상, 전이와 군무 조율을 소유한다.

## 1. 동작에 맞는 원천 선택

| 필요 | 우선 검토할 경로 | 그대로 맡기지 말 것 |
|---|---|---|
| 실제 사람의 무게감·익숙한 몸짓 | 권한이 확인된 실연/모캡 → 체형별 리타깃 | 원본 모캡도 새 발 크기·접시 단차·손잡이에 자동 적응하지 않음 |
| 이동·인사·반응·여러 동작 연결 | 로컬 Kimodo의 텍스트+키포즈/경로 조건 → 짧은 후보 비교 | 낯선 전문 동작, 손가락, 정확한 악기/소품 상호작용 |
| 음악 주도 춤 | 실제 안무 자료 또는 음악 조건 모델 후보 → 박자/장르 검토 | 음악 없는 일반 모션 모델에 BPM 문장만 넣고 박자 일치로 보고 |
| 궁중무용·특정 양식·영웅 동작 | 해당 양식 실연 분석 → pose-to-pose/모캡 기반 편집 | 일반 댄스/힙합 결과를 의상만 바꿔 전통춤이라고 명명 |
| 그릇·부채·창·악기·협동 운반 | 전신 기반 모션 + 손/소품 접촉 제어 | 자유 팔 동작을 손이 묶인 행동에 무조건 더하기 |
| 넘어짐·착지 반응·외력 적응 | 검증된 제어기+동역학, 또는 범위를 밝힌 키네마틱 연출 | 엔진/래그돌만 추가하면 스스로 균형·의도를 학습한다는 가정 |

모델/모캡 후보의 근거·실행 환경·권한 범위는
[motion-research-sources.md](motion-research-sources.md)에 있다. 새로운 모델을 선택할 때 읽고
현재 배포 상태를 다시 확인한다. 논문 데모, 코드 공개, 로컬 설치, 프로젝트 검증은 별도 상태다.
조사를 이유로 대용량 모델 설치·유료 생성·학습을 자동 시작하지 않는다.

## 2. 모션 목록 대신 행동 문법

각 구간을 `목적 | 준비 | 주요 행동 | 결과 | 회복/다음 행동`으로 만든다.
예: 무희가 인사한다→옆으로 체중을 옮긴다→팔의 호를 열며 돈다→관객 쪽으로 멈춘다→퇴장한다.
파일을 순서대로 붙이는 것이 아니라 다음 동작을 할 수 있는 끝 상태를 설계한다.

기본 보행, 춤, 작업, 반응, 협동을 모두 똑같은 반복 루프로 처리하지 않는다.
한 역할 안에서도 `모티프→변주→대비→회수` 같은 구성을 선택할 수 있다.
작은 손짓 뒤 큰 회전, 빠른 동작 뒤 정지, 몸을 낮췄다 펴기처럼 대비를 사용하되,
모든 장면에 춤이나 큰 동작을 억지로 넣지 않는다. 다양성은 랜덤 관절 노이즈가 아니다.

## 3. 연기 품질: 중간 프레임을 부드럽게 하는 것 이상

- 먼저 versioned performance contract의 primary beat, key pose, dominant accent와
  lead/follow order를 받는다. 없는 경우 해당 스킬로 설계하거나 누락을 명시한다.
- 주요 포즈와 중간 경로부터 만든다. 실루엣, 행동 목적, 지지·그립을 확인한 뒤 곡선을 다듬는다.
- 준비 동작, 가속/감속, 손·발의 경로, 몸통과 말단의 선후 관계를 의도에 맞춘다.
  모든 축에 같은 ease-in/out을 넣거나 매 프레임 사인파를 더하는 것은 연기가 아니다.
- 작은 소인이라도 멈춤·시선·호흡을 쓴다. 항상 발을 구르고 팔을 흔들어야 살아 보이는 게 아니다.
  필요한 과장은 타이밍/실루엣에 주고, 단단한 소품과 지지 발을 몰래 늘이거나 미끄러뜨리지 않는다.
- 주동작이 안정된 뒤 옷·장식·머리 등의 후행 움직임을 더한다. 지연이 항상 같은 값일 필요는 없다.
  천의 흔들림을 스켈레톤 흔들기로 대체하지 않고, 재질/물리 반응과 연기 제어를 구분한다.
- 무게·주의·성격을 연출 파라미터로 쓴다: 움직임 크기, 준비 시간, 시선 선행, 리듬의 여유,
  자세 높이, 방향 선택. 무작위 속도 변경이나 동일 액션의 seed만 바꾼 것을 별도 연기라고 주장하지 않는다.

## 4. 춤은 음악 프레이즈와 지지 상태를 같이 만든다

1. 사용할 음악의 실제 버전·구간·시작 오프셋을 확정한다. 박자, 강세, 쉼, 템포 변화의
   마커를 추출/확인한다. 자동 beat 검출은 초안이며 반박/배박 오류와 드리프트를 검토한다.
   음악을 듣지 못했으면 청취·음악성 검토는 미검증으로 둔다.
2. 안무를 프레이즈로 나눈다. 4박/8카운트는 해당 음악에 맞을 때만 사용한다.
   장단·변박·자유 리듬에 4/4 규칙을 강요하지 않는다. 속도만 있고 위상이 없는 BPM은 부족하다.
3. 어떤 사건이 강세에 닿는지 정한다: 발 착지, 동작의 정점, 몸통 악센트, 시선, 부채 펼침 등.
   매 박마다 모든 관절을 움직이거나 모든 프레임을 박자에 맞춰 snap하지 않는다.
   의도적인 당김/늦춤도 보존한다.
4. 발 접촉을 `고정 지지 / 피벗 / 의도적 슬라이드 / 공중 / 미확인`으로 나눈다.
   접촉 여부와 고정 여부는 다르다. 피벗은 발 전체가 아니라 실제 지지 패치를 검사한다.
   근거 없는 미끄러짐을 사후에 '의도적'으로 재분류해 통과시키지 않는다.
5. 리타이밍은 주요 사건 사이에서 완만하게 한다. 지지·발 구름·그립의 타이밍을 같이 옮기고
   순서와 속도를 재검토한다. 점프 비행 시간을 크게 늘이면 중력/높이도 영향을 받는다.
6. 춤에서는 진행 방향과 몸 정면이 달라도 정상이다. spins, side steps, backward steps를
   자동 전방 보정으로 지우지 않는다. 진짜 회전은 누적 각도/회전 이력을 보존한다.

박자 마커를 프레임으로 옮길 때는 `scripts/phrase_timing.py`를 사용할 수 있다.
실제 초 단위 마커에서 경계를 각각 계산하므로 프레이즈별 반올림 오차가 누적되지 않는다.
이 도구는 안무/오디오 분석기가 아니며, 입력된 박자가 올바른지 또는 모션이 그 박자를
따르는지는 검증하지 않는다. 모션 생성 프레임 수는 여전히 출력에서 확인한다.

실행 형태: `python scripts/phrase_timing.py assets/phrase-clock-example.json --out timeline.json`.
[예시 계획](../assets/phrase-clock-example.json)은 가정한 120 BPM의 16초 창작 동작이다.
음악 추출 결과나 생성된 애니메이션이 아니다. 구간은 `[start,end)`이고 Blender의 포함형
마지막 렌더 프레임으로 옮길 때는 `end_frame_exclusive - 1`을 쓴다.

## 5. 전이는 경계 포즈가 아닌 상태의 연결

경계 앞뒤 짧은 구간에서 root 위치·방향·속도, 주요 관절의 포즈/각속도,
지지 발/접촉 모드, 그립/소품, 음악 위상, 다음 행동 목적을 함께 비교한다.
정지 포즈 하나가 같아도 들어오는 속도나 지지 발이 반대이면 자연스럽게 이어지지 않는다.

- 같은 행동의 유사 위상: 좌표·루트 이동을 정렬하고 짧은 블렌드/관성 기반 전이를 검토한다.
  연결 결과에서 발/손 접촉을 다시 풀고 확인한다. NLA 보간은 접촉 솔버가 아니다.
- 지지·속도·방향이 다른 행동: 준비/디딤/회복을 포함한 bridge를 조건 생성하거나 작성한다.
  이전 끝과 다음 시작을 부드럽게 평균내는 것으로 불가능한 중간 동작이 가능해지지 않는다.
- 연속 생성: 앞 구간의 마지막 여러 포즈를 조건으로 주되 다음 동작을 실현할 시간을 남긴다.
  전체 프레임을 과도하게 고정하면 모델이 자연스러운 중간 동작을 풀 자유가 사라진다.
- 반복: 첫/끝 자세뿐 아니라 속도와 지지 위상, 이동 루트 누적값을 맞춘다. in-place와
  root-motion 모드를 구별해 루트 이동을 이중 적용하거나 반복마다 원점으로 순간이동하지 않는다.
- 회전 표현: 쿼터니언 부호 동등성과 Euler wrap을 처리하되, 360도 회전을 단순히
  시작=끝인 최단경로 보간으로 지우지 않는다. 회전의 중간 키와 경로를 보존한다.
- 영상 cross dissolve는 스켈레톤/접촉 연속성 수리가 아니다. 고정 투사에서 이중 팔다리와
  색 바램을 숨기기 위해 쓰지 않는다. 카메라 컷이 있어도 필요한 물체 상태는 이어져야 한다.

## 6. 군무와 역할별 다양성

공통 음악 시간과 대형 경로를 공유하되 배우마다 이동 통로·회전 반경·소품 공간을 갖는다.
동시 춤, 주고받기, 시간차 시작(canon)은 연출 선택이다. 동기화가 의도된 궁중 대형을
자연스러움이라는 이유로 무작위로 흐트러뜨리지 않는다.
시간차가 있는 배우의 손 전달/협동 운반은 같은 사건 시간에 다시 맞춰야 한다.

동작층의 소유권을 정한다. 하체 기반 보행 + 상체 인사는 가능하지만 몸통/균형 영향은 다시
검사한다. 양손 운반·큰 회전·점프처럼 전신성이 강한 동작에 마스크만 씌워 독립 합성하지 않는다.
두 배우가 서로 닿는 동작은 별도의 독립 모션 두 개가 아니라 상호 접촉 문제로 다룬다.

수라 프로젝트의 창작 예시: 무희는 팔의 호와 회전/정지를 중심으로, 시종은 쟁반 지지와
작은 보폭, 병사는 정돈된 진입과 정지, 악사는 호흡·운지·몸통 반응을 중심으로 설계한다.
이는 배역 제안이지 고증된 궁중 안무가 아니다. 정재 재현이면 정재별 자료를 직접 분석하고
원본 영상·음악·변환 모션의 이용 조건도 각각 확인한다.

## 7. 모션 라이브러리와 짧은 검증

각 후보에 `출처/권한, skeleton/FPS/단위, root 방식, 행동/양식, 박자 마커,
시작/끝 지지·속도·방향, 소품/그립, 사용 가능한 체형, 검증 버전/제외 범위`를 남긴다.
클립 숫자가 아니라 사용할 수 있는 완결 행동과 연결 가능한 상태를 늘린다.

한 캐릭터의 짧은 대표 시험을 먼저 만든다: 준비→걷기/춤 프레이즈→회전/정지→인사,
또는 집기→운반→놓기. 의도적 피벗/슬라이드가 있으면 각각 표시한다.
길이는 동작을 잘라내지 않는 범위로 정하고, 비싼 전체 렌더 전 진단 뷰와 정상속도로 확인한다.

검사는 따로 판정한다: 해부학/스킨, 접촉/관통, 전이 연속성, 음악 위상,
목적/무게감/매력, 배역·양식의 적합성. 낮은 jerk, 높은 beat 점수, 좋은 발 접지 수치 하나로
완성 판정하지 않는다. 팝핑의 강세를 전부 평활화하거나 정상 슬라이드를 고정하면 실패다.
작은 수의 후보를 정해 비교하고 같은 구조적 실패가 반복되면 seed 재시도보다 원천/조건/리그를 바꾼다.

실제 후보의 춤/전이 검수에는 설치된
[motion-and-dance-review.md](../../animation-causality-review/references/motion-and-dance-review.md)를 사용한다.
동반 스킬이 없으면 위 판정 범위를 프로젝트 기록에 남긴다.
