## Observable handoff block

Translate each craft term into the target, body part, order, visible result and
invariant. Examples:

- Not `add overlap`; write which driver stops, which sleeve/finger/head follows,
  how long qualitatively, and what grip/support cannot change.
- Not `moving hold`; write which silhouette/gaze/contact stays fixed and which breath,
  eye, finger or cloth detail remains alive.
- Not `cute Pixar-like`; write the restrained asymmetry, readable intention, timing
  contrast and personality-specific recovery desired without naming a style target.
