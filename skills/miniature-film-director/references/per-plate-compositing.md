# 접시별 배경 제거 → 네 좌석 배치 → 배경 합성

이 테이블 시리즈의 현재 순서다. 기존 한 접시 영상과 사용자가 고른 배경을 재사용한다.
접시·캐릭터의 크기, 성공 프롬프트, 카메라와 동작을 합성 때문에 다시 생성하지 않는다.

## 한 접시에서 먼저 분리·검수

- 각 소스에서 접시·캐릭터·의상·소품·음식/액체를 하나의 전경 단위로 분리한다.
  같은 영상 반복 사용이면 검수한 분리본을 재사용한다. 서로 다른 영상이면 각각 처리한다.
- 원본 RGB, 동기화된 알파/마스크, 실제 제거 결과와 해시를 보존한다. MP4나 검은 배경
  미리보기라는 이유로 투명 출력이라고 단정하지 않는다. 코덱·픽셀 형식과 실제 마스크를 확인한다.
- 현재 사용 가능한 제거 도구의 입력·출력을 확인하고 승인된 범위에서 사용한다.
  특정 서비스의 피사체 보존 설명은 우리 접시·복수 인물·도구가 보존됐다는 검수 근거가 아니다.
- 초록색 옷과 제작 배경을 구분한다. 머리·손·나무 도구·우유·접시 내부가 지워졌거나
  마스크에 구멍이 난 결과를 배치 단계에 넘기지 않는다. 원본의 보호 마스크를 활용해 국소 수정할
  수 있으며 실패한 유료 제거 작업을 자동 재시도하지 않는다.

## 경계 떨림 보정

고정 접시의 실제 경계가 소스에서 안정적인지 확인해 고정 마스크를 재사용한다.
움직이는 인물·소품의 경계는 동작에 맞춰 앞뒤 마스크를 정렬하고, 가림/빠른 동작에서
정렬이 불확실한 픽셀은 보정 강도를 줄인다. 단순 시간 평균은 움직이는 손과 도구에 잔상을
만들 수 있다. 전체 RGB에 블러를 적용하지 않고 필요한 알파 경계만 좁게 보정한다.
경계의 배경색 잔여를 제거할 때는 의상의 본래 색을 보호한다. 원본 자체의 모양 떨림과
분리 때문에 생긴 떨림을 구분해 실제 결과에서 비교한다. 특정 페더 폭/필터가 모든 소스에 맞지는 않는다.

체커보드·어두운 배경·최종 배경에서 시작, 동작 중, 끝과 빠른 도구 구간을 확인한다.
기술 검사나 경계 오차 감소를 정상속도 시각 검수의 통과로 바꾸지 않는다.

## 네 좌석과 선택 배경

분리본의 RGB와 알파를 함께 회전·크기 조정·배치한다. 리사이즈는 알파 경계의 색 번짐을
확인하며 필요한 경우 premultiplied-alpha 처리를 사용한다. 미러링으로 방향을 대체하지 않는다.
현재 서로 마주 보는 두 쌍은 위쪽 둘 180도, 아래쪽 둘 0도이며 실제 프로젝트 좌표를 따른다.
배경 제거는 네 접시 배치 이전에 끝낸다. 배치한 합성본을 다시 리무버에 넣는 단계를 기본값으로 삼지 않는다.

제공된 배경은 비율·중앙 문양을 보고 맞춤/크롭/반복 방법을 정해 기록하며 접시 아래까지
이어지게 한다. 배경만 바꾸려는 요청이면 기존 전경을 로컬 합성한다. 생성형 영상 편집은
요청한 경우에 선택하고 전경의 모양·위치·동작 보존을 실제 후보에서 별도로 확인한다.

기존 [compose_seat_tiles.py](../scripts/compose_seat_tiles.py)는 단색 초안에서 비어 있는
사각 타일 외곽을 잇는 도구다. 전경 분리나 임의 배경 합성용으로 오인하지 않는다.
새 출력은 원본·마스크·배경·배치 파라미터에 연결하고 전체 디코딩·길이·FPS·음향을 검사한다.
행동/접촉 판정과 물리 프로젝터 정렬은 배경 합성으로 새로 승인된 사실이 아니다.
