# Causal and editorial bridges

| Situation | Readable design | Do not substitute |
|---|---|---|
| A tool is needed | Establish rack, carried-in state or opening grip; show reach/contact if needed | Tool materializes in an empty hand |
| Lift/transfer | Approach, grip, source release, travel, new support, release | Glow conceals missing load transfer |
| Ingredient choreography | Batch/source, controlled path, arrival, accumulation | Complete dish pops in while unrelated ribbons fly |
| Magic | Declared rule, perceptible trigger and consequence | Retroactive excuse for a continuity error |
| Full-screen fan wipe | Motif-led foreground graphic covers complete raster; hidden edit; reveal | Four plate-local masks |
| Local food reveal | Named interior masks cover an editorial swap; registered rims | Vegetables physically mutate into meat |
| Match on action | Action phase, direction and attention link across cut | Colors match while hands reset |
| Graphic match | Shape/position links scenes; changed setting/time understandable | Similar outline proves same physical object |
| Audio bridge | Sound source or musical relation carries edit | Whoosh alone excuses sudden prop |
| Welcome asset | Settle, dim, composite original at intended position/native speed | Regenerated text, duplicate circles or accelerated loop |

## Wipe contract

Name direction, full/local region, opacity, coverage interval, hidden edit, reveal
direction and outgoing/incoming states. A transition graphic can differ from the
small physical fan; connect by motif/gesture without pretending a tiny dancer
carries a table-sized prop.

Show opaque fan interior across all corners. In implementation test the mask
over the complete replacement region at every edit frame. Motion blur, feathered
edges and translucent petals can expose holes; padding outside the raster is valid.
Keep the projection camera registered while allowing the requested scene edit.

## Example: fan → platter → banquet → welcome

This is proposed projection-stage fantasy, not verified animation.

- A fan gesture introduces the same motif in a full-screen wipe. Under complete
  coverage, change scenes. Dancers become readable as it clears, before ingredient
  paths start. Sources are established trays or explicitly declared magic, not
  unexplained empty air. Travel and accumulation precede the presentation hold.
- If timing is too short, reduce batches or change the interval, not the physical
  speed into a teleport. A drum can motivate a banquet edit, not literally cook food.
- At the end performers settle and light yields to one centrally placed supplied
  welcome loop if requested. Preserve typography, proportions and playback phase.
  A loop longer than the outro continues beyond it; do not speed up or reset it.

These are examples, not defaults. Preserve a requested surprise, comic cut,
different camera or realistic cooking sequence rather than imposing this story.
