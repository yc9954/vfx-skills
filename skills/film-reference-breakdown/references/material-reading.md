# 귀여운 사실감을 분해해서 읽기

“르쁘띠 셰프 느낌”, “AI 같지 않게”를 재질 프리셋이나 모델명으로 치환하지 않는다.
비교할 실제 목표 프레임과 후보를 같은 크기로 놓고 다음 원인을 구분한다.

| 축 | 관찰 | 제작에서 바꿀 것 |
|---|---|---|
| 형태/규모 | 머리·손·발 비율, 눈 크기, 접시 대비 신장 | 실루엣과 실제 치수 |
| 천/피부 | 직조 크기, 매트함, 하이라이트 폭 | 거칠기·법선·약한 표면 불균일 |
| 도자기/금속 | 반사 윤곽, 유약, 손잡이 마모 | 서로 다른 재질 반응 |
| 물/수프 | 투명도·깊이·점성 인상, 파동 속도 | 흡수·반사·기하·접촉 효과 |
| 조명 | 접촉 그림자, 부드러움, 흰 옷의 밝기 | 광원 크기·방향·노출 |
| 촬영/투사 | 번짐, 색 바램, 모아레, 압축 | 표시 환경과 재질 자체를 분리 |

실제 프로젝션을 휴대전화로 찍은 영상의 탈색·노이즈를 고유한 PBR 재질로 복제하지 않는다.
원본이 부드럽다고 낮은 해상도나 전체 블러로 모방하지 않는다. 과도한 DOF는 소인과 손동작을 지운다.
프레임마다 노출을 바꾸어 연결을 맞추면 새 펌핑이 생긴다. 조명/색관리 기준을 고정한 비교 렌더를 쓴다.

가장 영향 큰 차이부터 한 번에 소수만 바꿔 동일 구도의 시험 프레임/짧은 동작으로 비교한다.
미세 노이즈 절차 텍스처가 캐릭터보다 큰 줄무늬나 모아레가 되지 않는지 납품 크기에서 본다.
정지 이미지가 좋아졌다는 것과 움직이는 영상의 질감이 일관된다는 것은 별도 판정이다.

## 물과 소품이 따로 보일 때

소품 하나의 텍스처가 아니라 **경계**를 비교한다: 실제 수면 높이, 잠긴 부분의 색/가림,
굴절·깊이에 따른 가시성, 젖은 띠, 접촉 그림자, 사건 위치의 물결·거품. 물 아래 산호와
바위가 수면 위 소품만큼 선명하다면 깊이 단서를 확인한다. 접시 두께·선체 부피를 늘려
가짜 접촉을 만드는 제안은 피한다. 고정 시점·노출의 전/중/후 프레임으로 비교한다.

불은 광원에 의한 주변 밝기와 실제 보이는 불꽃의 형상·발생점·길이·가림·시간 변화를
따로 기록한다. “밝아졌다”가 “불꽃처럼 보인다”의 근거는 아니다. AI 원본의 형태가
흔들리는 오류까지 재현하지 말고 유지해야 할 재질·색감·사건의 읽힘을 추출한다.

## 목표 질감과 거절 기준을 함께 남기기

위 표에서 중요한 차이를 네 가지로 요약한다: **느낌의 핵심**, **재질 언어**,
**구조/비율 규칙**, **색과 빛**. 목표 프레임/시간과 함께 관찰인지 제작 제안인지 표시한다.
예를 들어 “수제 소인 애니메이션, 무광 피부와 부드러운 천, 접시 아래로 이어지는 배경,
흰 옷의 디테일이 남는 부드러운 빛”처럼 비교 가능한 언어를 쓴다.

그 다음 해당 작업에서 실패할 모습을 적는다: 봉제인형처럼 커진 머리, 모든 물체의
같은 플라스틱 광택, 접시 둘레의 빈 고리, 블러에 사라진 손동작 등. 실제 레퍼런스가
다른 선택을 보여주면 예시를 강요하지 않는다. 낮은 해상도·필름 그레인·피부 모공을
일괄 추가하는 것은 스타일 개선 기준이 아니다.

새 이미지 프롬프트가 필요하면 설치된 `visual-image`의 스타일 계약을 사용할 수 있다.
분석만 요청받았다면 이미지를 생성하지 않는다. 모든 비교는 실제 후보 버전에 연결한다.
