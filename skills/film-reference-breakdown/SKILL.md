# 영상 레퍼런스 분석

코드를 쓰기 전에 무엇이 보이고 어떤 원인으로 움직이는지 기록한다. 이 스킬은
관찰 자료를 만든다. 분석 요청만으로 영상을 새로 생성하거나 외부에 업로드하지 않는다.

## 입력을 확정

- 실제 파일/접근 가능한 원본을 열고 길이, FPS/시간 기준, 해상도, 음향 유무를 확인한다.
  여러 후보면 요청과 생성 기록으로 구분한다. 여전히 구분 불가하면 임의 파일을 최신작이라 부르지 않는다.
- 출처와 사용 구간을 기록한다. 서로 다른 영상의 조각을 합쳤다면 클립별 원본 시간 범위를 남긴다.
- 최신 스토리 개정과 영상의 역할을 구분한다. 이야기가 바뀌어도 유효한 질감/연기 자료는
  재사용하되, 삭제된 사건이나 나중에 등장할 재료를 첫 장면에 전부 배치하지 않는다.
  접근하지 못한 최신 문서는 이전 버전으로 읽은 척하지 않는다.
- 전체 이야기부터 파악한 뒤 상호작용을 촘촘히 본다. “프레임 단위 분석” 요청이면
  분석 범위의 모든 프레임을 추출/계측하고, 사람이 읽는 주요 장면표와 구분한다.
  실제로 시각 검토한 범위를 명시한다. 추출만 했다고 모든 프레임을 보았다고 하지 않는다.

## 행동과 엔티티를 분리

[observation-contract.md](references/observation-contract.md)의 표 형식으로 간결하게 기록한다.

- 행동마다 준비→접근→접촉→하중 이동→이동/변형→놓기→회복을 구분한다.
- 발/손뿐 아니라 머리·시선·척추·골반·팔꿈치·도구·재료·지지물의 관계를 본다.
- 전신 리깅/움직임의 자료를 만들 때는 발뒤꿈치·앞꿈치·발끝의 접촉 변화, 무릎의 굽힘 방향,
  골반/가슴의 분담, 어깨대와 팔의 도달을 함께 기록한다. 관절 하나의 끝 자세만 복제하지 않는다.
  의상에 가려진 무릎/견갑 움직임은 추론으로 표시하고, 보이는 골반점을 실제 질량중심으로 부르지 않는다.
- 소품은 화면에 등장하는 순간이 아니라 실제 세계의 시작 위치부터 추적한다.
  가려진 원인이 있으면 “가려져 미확인”이라고 쓴다.
- 카메라/편집에 의한 변화와 물체의 운동을 구분한다. 소스의 순간이동, AI 형태 변형,
  컷 경계의 배치 불연속은 재현해야 할 안무가 아니다.
- 화면 전경/중심점 추적은 2D 측정이다. 이를 관절별 모션캡처나 가려진 손의 3D 복원으로 설명하지 않는다.

손으로 물체를 다루는 장면에서는 [hand-reference-protocol.md](references/hand-reference-protocol.md)를
추가로 읽는다. AI 레퍼런스의 잘못된 손을 정답 포즈로 복제하지 않는다.

## 질감이 문제일 때

[material-reading.md](references/material-reading.md)를 읽고 형태·재질·빛·카메라를 나눠 비교한다.
사용자가 거절한 AI 이미지가 아니라 실제 목표 레퍼런스를 기준으로 삼는다.

## 결과

필요한 범위에서 출처표, 프레임/시간별 행동표, 엔티티 목록, 질감 비교,
핵심 접촉의 전/중/후 증거와 제작 결정만 전달한다. 큰 CSV가 필요하면 별도 파일로 둔다.
정상속도 움직임이나 오디오를 지각할 도구가 없으면 정지 프레임/측정 기반 분석임을 밝힌다.
분석 결과는 Blender 제작의 입력이며 자동으로 자연스러움의 승인이 되지 않는다.

분석만 요청받았다면 여기서 끝낸다. 제작까지 요청됐다면 이 자료를 제작 단계로 넘기고,
실제 후보의 품질 검토가 필요할 때 검수 스킬을 사용한다. 같은 원본 버전의 유효한 분석은 재사용한다.
다단계 제작에 기록이 있으면 원본 버전·시간표·관찰과 추론·다음 행동을
[공통 인계 규약](../miniature-film-director/references/handoff-contract.md)에 맞춰 넘긴다.
동반 스킬이 없으면 같은 내용을 기존 프로젝트 노트에 남긴다. 분석 요청만으로 새 제작 기록은 만들지 않는다.
