# 접촉으로 움직임 만들기

사람의 하중·ROM·균형 용어는 공통
[human-motion contract](../../human-motion-biomechanics/references/motion-language.md)와
[load/balance guide](../../human-motion-biomechanics/references/load-balance-and-handling.md)를 따른다.
이 파일은 그 계약을 Blender의 포즈·IK·제약 전환으로 옮기는 구현 규칙을 소유한다.

연기 설계가 필요한 장면은 먼저
[character performance contract](../../character-performance-animation/assets/performance-beat-packet.md)의
objective, thought/emotional beats, key poses, gaze/face, timing accents와 overlap order를 받는다.
이 파일은 그 의도를 실제 컨트롤과 접촉 상태로 옮기며 새 성격 문법을 중복 정의하지 않는다.

## 연기 블로킹 패스

1. performance key pose를 stepped로 놓고 delivery camera에서 실루엣·prop relation을 확인한다.
2. 같은 포즈에 biomechanics의 지지/ROM/하중/그립을 적용한다. 불가능하면 손을 clamp하거나
   리그를 늘이지 말고 line of action과 감정 방향을 보존한 대체 포즈를 찾는다.
3. 눈→머리→몸, 몸통→어깨→팔→손처럼 지정된 lead/follow breakdown을 넣는다.
4. moving hold에서는 고정할 grip/support/silhouette과 살아 있을 breath/eyes/fingers/sleeves를
   서로 다른 컨트롤 층으로 둔다. random noise나 전신 사인파를 쓰지 않는다.
5. primary action과 접촉이 통과한 뒤에만 얼굴·손가락·옷의 secondary/tertiary polish를 더한다.
6. 정상속도, silhouette/stepped, 접촉 확대를 각각 확인한다. 어느 하나가 다른 검사를 대신하지 않는다.

## 하중 동작의 블로킹 순서

1. 소품의 시작 지지, 목적지 지지, 실제 접촉면과 하중 가정을 고정한다.
2. 발/지지면과 골반·몸통을 먼저 배치해 손 목표까지의 여유를 만든다.
3. 어깨대→팔꿈치→전완→손목 순으로 작업 범위를 확인한다. 손목 한계에 가까우면
   손목을 clamp하지 말고 손잡이, 팔꿈치, 어깨, 몸통, 발 배치를 다시 조율한다.
4. 양손이면 각 손의 `support/control/stabilize` 역할과 패치·엄지 대향을 정한다.
5. 손가락 접촉과 그립이 생긴 뒤에만 기존 지지를 해제하고 소품 하중을 손으로 넘긴다.
6. 소품이 몸에서 멀어져 moment arm이 커지면 골반/몸통·발의 대응을 함께 만든다.
7. 감속→새 지지→그립 해제→손 이탈→전신 settle까지 완결한다.

침투 감소만 최적화하지 않는다. 먼저 허용 가능한 전신 자세와 올바른 접촉 방향을
확보한 다음, 장면 스케일에 맞는 오차로 간격/교차를 줄이고 subframe 경로를 검사한다.

## 걷고 멈추고 돌아보기

- 이동 거리·속도와 실제 다리 길이에 맞춰 보폭/보행 시간을 정한다. 신장에 관계없는
  큰 보폭, 일정 시간마다 발을 따라잡게 하는 임계값 규칙은 꼭두각시 느낌을 만든다.
- 발을 들기 전 지지 다리로 체중을 옮긴다. 지지 발은 세계 좌표에서 안정되게 두고,
  스윙 발은 발끝 이탈→여유 높이→착지/충격 흡수로 이어진다. 발목 점과 발바닥을 따로 검사한다.
- 골반 높이는 고정 상수가 아니라 다리 길이와 무릎 여유를 고려한다. 정지 상태에서
  과도한 무릎 굽힘이나 계속 발을 구르는 루프가 남지 않아야 한다.
- 전방 축은 해당 리그의 정면 테스트로 보정한다. 이동 속도와 몸 방향을 비교하되,
  의도적인 뒷걸음/옆걸음까지 강제로 앞으로 돌리지 않는다. 시선과 몸 전방은 다를 수 있다.
- 회전에는 발 재배치나 피벗이 필요하다. 양발이 고정된 채 몸만 큰 각도로 비틀지 않는다.
- 팔은 다리와 반대 위상으로 자연스럽게 움직이고, 몸통/골반 회전·가속·하중의 영향을 받는다.
  짐을 들면 자유 팔 흔들기를 중단하고 어깨·팔꿈치·손목의 하중 반응을 새로 만든다.
- 점프는 웅크림→밀기→비행→착지→회복. 접지 보정은 지지 구간에만 적용한다.

## 손과 모자·손잡이

- 소품은 처음부터 합리적인 장소에 존재한다. 손 접근→손목 정렬→손가락 닫힘→
  하중 이동→기존 지지 해제→들기 순서다. 놓을 때는 새 지지가 먼저다.
- IK 목표가 사지 길이를 넘으면 실패를 기록하고 자세/배치를 고친다. 목표를 몰래
  clamp하거나 뼈를 늘린 뒤 손이 닿았다고 하지 않는다. 양손과 팔꿈치 여유도 같이 확인한다.
- 모자는 머리와 분리할 공간이 필요하다. 머리를 통과시키거나 한순간 다른 소품으로 바꾸지 않는다.
- 손가락 뼈가 없으면 메시 변형 키를 쓸 수 있으나 실제 손잡이를 감싸는지 확인한다.
  Blender `shape_key_add`는 기본 `from_mix=True`로 현재 혼합 변형을 복사할 수 있다.
  독립적인 좌/우 그립은 `from_mix=False`와 기준값 초기화를 고려하고 왼손만/오른손만/
  양손 상태에서 반대 손의 정점이 중복 변형되지 않는지 검사한다.

## 뜰채·재료·수프

- 시간만 되면 재료를 망에 parent하지 않는다. 재료 크기를 고려해 열린 입구로 들어오는
  상대 경로를 만든다. 접근 시작부터 망 바닥·측면·테두리가 재료를 통과하지 않는지 본다.
- 망의 깊이, 입구 크기, 실제 재료 크기, 중력 방향으로 지지를 설명한다. 표면적 교차 없음은
  완전 포함/통과가 없다는 증명이 아니다. 빠른 이동은 서브프레임 또는 swept 검사를 쓴다.
- 들어올린 물은 배수되고, 재료는 용기 바닥의 지지로 유지된다. 단순 parent 유지로
  뒤집힌 망에 달라붙어 있으면 안 된다.
- 붓기는 기울이기→낮아진 림으로 이동→충분한 출구 여유→분리→낙하→수프/그릇 접촉이다.
  뜰채를 내리기만 해서 재료를 분산시키지 않는다.
- 줄이 있다면 손이 당긴 길이, 풀리 배율, 장력/처짐, 선회·기울임 원인을 맞춘다.
  떠다니는 바구니에 줄을 덧그렸다고 도르래 작동을 구현한 것은 아니다.
- 물결/거품/비말/증기/소리는 실제 사건 위치와 시점에 연결한다. 사실적 셰이더와
  유체·부력 시뮬레이션은 다른 구현이다. 필요한 범위의 근사를 명확히 적는다.

## 구현 함정

- Blender 버전에 맞는 Action slot/channelbag API를 확인한다. 기존 Action을 덮기 전에
  공유 데이터와 사용자 키프레임을 확인하고 해당 배우의 복제본을 만든다.
- modifier RNA 래퍼는 접근마다 달라질 수 있다. Python `is` 기반 정렬 종료 조건은
  무한 반복할 수 있으므로 안정된 이름/순서와 제한된 횟수로 처리한다.
- 장면 좌표의 허용오차를 사람 크기에서 그대로 가져오지 않는다. 작은 셰프에게 1cm는 큰 거리다.
