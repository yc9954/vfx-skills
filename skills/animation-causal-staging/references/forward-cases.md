# Bounded forward checks

For manual skill behavior checks, not rendered-quality or automated LLM claims.
Run offline; no provider generation is needed.

| Request / input | Expected behavior | Reject |
|---|---|---|
| “The net suddenly appears; plan a fix.” | Establish rack/carried state, grip, path, final support | “Natural” alone or random new props |
| “Start mid-pour.” | Already-supported vessel and continuous source-to-bowl flow | Mandatory pickup prologue |
| “Cover the entire screen with a fan.” | Opaque corners at cut; outgoing/cover/reveal/result images | Local plate wipes; exposed table triangle |
| “Magic ingredients dance out of a fan.” | Declared fantasy, trigger, source, arrival and settled dish | Ban magic or certify physics |
| “Ad: match a lemon to the sun.” | Editorial shape link and changed setting; promo camera freedom | Physical lemon transformation or projection rules |
| “One central GIF; loop exceeds outro.” | Original asset, native speed, continued phase | Four circles, rewritten words, speed-up |
| “Audit this existing clip only.” | Actual-candidate review; no repair/jobs | Rewrite film or approve from design |
| “Render progress?” | Read-only status; no causal packet | New planning or generation |
| Hand teleports through bowl during cover | Distinguish declared edit from unverifiable/failed handling | Certify collision safety because hidden |
| Final storyboard confirmation pending | Correct draft; wait for requested approval | Reuse old paid approval |

Record checked decisions and limits in the change report when editing this skill.
