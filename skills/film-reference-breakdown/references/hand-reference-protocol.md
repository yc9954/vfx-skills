# 손·도구 레퍼런스 관찰

전체 동작의 접근/접촉/하중/해제 구간 중 손이 읽히는 프레임을 확보한다.
이미지가 작거나 손이 가려졌다면 접촉 패드와 엄지 방향을 추측한 확정값으로 쓰지 않는다.
정지 이미지 하나는 그립 타이밍·하중 이동·편안한 관절 범위를 증명하지 않는다.

각 손에 대해 다음을 짧게 기록한다:

`time | palm/back visible | thumb opposition | fingers contacting what | forearm/wrist orientation | source of support | visible/occluded/inferred`

손가락이 보인다고 개수를 세는 데서 끝내지 않는다. 관절 꺾임, 손톱/패드 방향,
엄지 위치, 손바닥 아치, 소품에 맞춘 손 벌림, 손목과 팔뚝의 연속성을 본다.
잡는 힘/무게는 영상만으로 정량 복원하지 않는다. 양손 받침과 한 손 정밀 잡기를 구분한다.

형태가 바뀌거나 역관절인 AI 영상은 질감/연출 참고로만 쓸 수 있다. 그립 구조는
사용 가능한 실제 인체/도구 동작 자료와 대조한다. 해부학 근거는 설치된
`blender-contact-animation/references/hand-biomechanics.md` 또는 직접 확인한 전문 자료를 사용한다.
참고 자료의 이용권한과 외부 업로드 권한은 별도다.

필요한 추가 자료를 제작자가 확보할 수 있으면 먼저 조사한다. 사용자가 직접 모션캡처하거나
코드를 작성하도록 불필요하게 떠넘기지 않는다. 자료가 끝내 없으면 불확실한 관절/접촉을
명시하고, 제작 단계의 중립→작은 굽힘→소품별 테스트에서 해결하도록 넘긴다.
